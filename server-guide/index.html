Подготовь свой сервер

Твоя часть — около 20 минут. Открывай шаги по очереди. Остальное я сделаю сам.

01 Шаг 1 · 10 мин Регистрация на 4VPS
  1. Открой 4vps.su по этой ссылке и нажми «Войти» справа вверху.
  2. Нажми «Создать аккаунт».
+10% к пополнению

Если зарегистрироваться по этой ссылке, к пополнению баланса добавят 10%. Поэтому открывай сайт именно по ней, а не набирай адрес вручную.

  1. Заполни логин, почту и пароль два раза. Нажми «Зарегистрироваться». Если на почту придёт письмо, подтверди её.

Выбор сервера

  1. Вернись на главную 4vps.su и в разделе «Начни с выбора Дата-Центра» нажми «Нидерланды».
  1. Ниже проверь, что выбрано. Разбираться в этих словах не нужно, просто сверь:
    • Нидерланды, Амстердам SkyLink
    • VPS на базе AMD EPYC 7763
    • 1 месяц
  1. В списке тарифов найди строку NL-cx31 и нажми «Арендовать».
Про оплату

Цена указана в той же строке. Платить нужно каждый месяц: если не продлить, сервер отключат вместе с Claude.

Оформление и оплата

  1. В поле «Выберите OS» выбери Ubuntu 24.04.
  1. В поле «Придумайте имя серверу» впиши любое имя латиницей, без пробелов. Например: MyServer.
  1. Всё остальное, что предлагают за доплату (панели, лицензии, бэкапы), не отмечай.
  2. Оплати российской картой или по СБП.
  3. Через несколько минут в личном кабинете или в письме появятся данные сервера: IP-адрес (четыре числа через точку, например 185.12.34.56) и пароль.

Где взять IP и пароль

  1. Зайди в личный кабинет 4vps.su, вкладка «Сервера». Справа от своего сервера нажми стрелку.
  1. В блоке «Основная информация» найди строку IPv4 — это IP-адрес.
  2. В блоке «Пароль» нажми на глазик — пароль станет видно.
  1. Скопируй IP-адрес и пароль и пришли мне в Telegram.
02 Шаг 2 · 10 мин Зарубежная карта

Уже платишь за Claude и оплата проходит — пропусти этот шаг.

Claude принимает только зарубежные карты: российские Visa, Mastercard и МИР не проходят. Выпусти карту в сервисе «Плати по миру». Всё онлайн, без документов. Пополняешь рублями по СБП.

Честно: выпуск карты платный, цена — на сайте сервиса. Первый год обслуживания бесплатный.

  1. Открой «Плати по миру» по этой ссылке и нажми «Оформить карту».
  2. Выбери карту «Для подписок» и нажми «Выпустить карту для подписок». Бери именно её: с неё оплачиваются нейросети, в том числе Claude.
+$5 на карту

Если это твоя первая карта в «Плати по миру» и ты выпускаешь её по этой ссылке, тебе на карту придут $5. Поэтому открывай сайт именно по ней.

  1. Введи свою почту, нажми стрелку справа от поля и введи код из письма.
  1. Поставь галочку согласия, нажми «Перейти к оплате» и оплати выпуск по СБП.
  2. Пополни карту в личном кабинете с запасом, на $25–30. Подписка Claude Pro стоит $20, и к ней может добавиться налог.
03 Шаг 3 · 15 мин · для тарифа «Профи» Четыре Telegram-бота

Через этих ботов Claude будет работать с тобой прямо в Telegram:

  • Главный — пишешь задачу, Claude выполняет её на сервере.
  • Файлы — присылает отчёты и готовые файлы, принимает голосовые.
  • Рилсы — присылаешь ссылку на рилс, получаешь разбор и идеи.
  • Насмотренность — присылаешь удачный дизайн, Claude запоминает образцы.
Start в новых ботах пока не нажимай

Хозяином бота становится тот, кто первым нажмёт Start. Я напишу, когда пора. Start нужен только у BotFather.

Как создать одного бота

  1. Открой @BotFather в Telegram. Проверь, что рядом с именем синяя галочка: это официальный бот Telegram, остальные — подделки. Нажми Start.
  2. Отправь ему команду /newbot.

  1. Напиши адрес бота латиницей, без пробелов, в конце обязательно bot. Например: anna_main_bot. Если ответит, что адрес занят, — придумай другой.

  1. Сохрани токен у себя в заметках и подпиши, какой это бот.

Токены — только мне

По токену любой может управлять ботом. Не публикуй их и не отправляй никому, кроме меня. Ссылки на ботов тоже не раздавай.

Как подключу ботов, напишу, когда нажать Start в каждом. После этого в бота «Файлы» придёт проверочное сообщение — значит, всё работает.

04 Шаг 4 · 10 мин · для тарифа «Профи» GitHub — копия твоих данных

GitHub — сервис, куда каждую ночь будет сохраняться копия всего, что есть на твоём сервере. Если с сервером что-то случится, всё восстановим из неё. Пароль от GitHub мне не нужен.

Аккаунт если ещё нет

  1. Открой github.com/signup.
  2. Впиши почту, придумай пароль и логин (Username) — латиницей, например anna-claude. Нажми Continue.
  3. Пройди проверку «я не робот» и введи код из письма, которое придёт на почту.

Мой логин на GitHub: ...

Вставь мой ключ

  1. Впиши сюда свой логин — ниже появится ссылка прямо на нужную страницу:
    Открыть страницу ключа ↗
    Не открылось? В хранилище server-backup: Settings → слева Deploy keys → Add deploy key.
  2. В поле Title напиши server.
  3. В поле Key вставь мой ключ целиком, одной строкой.
  4. Поставь галочку Allow write access. Без неё сервер не сможет сохранять копию.
  5. Нажми Add key и напиши мне «готово».
